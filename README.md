## 🛠️ Technical Specifications
This drone is designed to be extremely lightweight, utilizing the PCB itself as the Airframe.

- **Microcontroller**: ESP32-WROOM-32 (Wi-Fi & Bluetooth)
- **IMU**: MPU6050 (6-axis Gyroscope + Accelerometer)
- **Motors**: 4x Coreless Motors driven via PWM
- **Drivers**: SI2302 MOSFETs (N-Channel)
- **Power**: 1S LiPo Battery (3.7V) with integrated USB charging

## 📂 Project Structure
- `Firmware/`: ESP-IDF based source code.
- `Hardware/`: Circuit schematics, PCB Gerber files, and PVC frame blueprints.
- `Documentation/`: Technical analysis and assembly guides.

## 🚀 Getting Started
1. **Hardware**: Follow the schematics in the `Hardware` folder to assemble the PCB.
2. **Firmware**: Use `idf.py build` in the `Firmware` folder to compile the code.
3. **Flash**: Connect the ESP32 and run `idf.py flash`.
4. **Flight**: Connect to the Wi-Fi network generated by the drone and use the dedicated app for control.
